# Production decision
Recommended design: hybrid deployment. Keep baseline/internal workloads on university infrastructure and use public-cloud capacity for result-day surge. Run stateless portal replicas as containers behind a load balancer/WAF; use a highly available managed relational database with backups.
VMs provide OS isolation but require more guest memory and patching. Containers start quickly and use resources efficiently but share the host kernel. Kubernetes adds scheduling and recovery across nodes but requires operational skills. Public cloud adds capacity quickly but incurs compute, database, storage, load-balancer, monitoring, transfer and support charges. Hybrid balances baseline control and burst capacity but requires secure connectivity and data governance.
Calculate actual yearly cost from university hardware/power/staff plus cloud baseline and two result-day peak events. Use provider quotations; do not claim one option is cheapest without real costs.
